# MobiFlight devcontainer

Devcontainer for MobiFlight development, based on typescript-node:latest.

## Usage

```json
"image": "ghcr.io/neilenns/devcontainers/mobiflight:latest"
```

Also, copy the `post-create.sh` file to your `.devcontainer` folder. This will run after the container is created, and is used to install any additional tools.

## Installed features

- zsh
- Shell history

## Installed vscode extensions

- Github actions
- Markdown all-in-one
- Markdown footnote
- Markdownlint
- Prettier
- Remote containers
